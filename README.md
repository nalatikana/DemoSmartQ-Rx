# Pharmacy Queue System Demo

เว็บเดโมระบบคิวห้องยาแบบ real-time สำหรับนำเสนอ flow ให้ลูกค้าดูบน GitHub หรือเปิดทำงานใน VS Code ได้ทันที

## ฟีเจอร์หลัก

- หน้า Login ก่อนเข้าใช้งาน พร้อมบัญชีเดโมตามสิทธิ์
- หน้าจอทีวีสำหรับผู้ป่วย พร้อมประกาศวิ่ง คิวปัจจุบัน และคิวที่ถูกข้าม
- หน้าควบคุมพนักงานห้องยา: Next, Recall, Skip, Manual Recall, ช่องเรียกคิวด้วยเลขที่ต้องการ, รายการคิวรับยาแล้ว และ Cooldown กันกดซ้ำ
- รายการคิวที่ถูกข้ามแสดงเป็นกล่องเล็กหลายคิวต่อแถว พร้อมปุ่ม `รับยาเลย`, `เรียกย้อนหลัง`, และ `ยกเลิก`
- ปุ่ม `รับยาแล้ว` ของคิวปัจจุบันจะปิดคิวนั้นและเรียกคิวถัดไปให้อัตโนมัติในคลิกเดียว
- ปุ่มเลือกช่องรับยา 2 ช่อง: ช่องรับยา 1 และช่องรับยา 2
- การเรียกคิวแบบ Manual ไม่ทำให้ลำดับคิวถัดไปกระโดด เช่น เรียก 020 แล้วปุ่ม Next ยังกลับไปเรียกลำดับถัดไปจริง
- Dashboard ผู้บริหาร เลือกวันที่ดูย้อนหลังได้ พร้อมประกาศของวันที่เลือก
- Export Excel ได้ทั้งรายงานการเรียกคิวและสรุป Dashboard
- หน้า Admin สำหรับแก้ประกาศ ดูผู้ใช้ และ Audit Logs
- ซิงก์ข้อมูลข้ามแท็บแบบ real-time ด้วย `BroadcastChannel` และ `localStorage`
- รีเซ็ตเลขคิวใหม่อัตโนมัติเมื่อข้ามวัน

## บัญชีสำหรับเดโม

- `nurse` / `1234` สำหรับหน้าพนักงานห้องยา
- `manager` / `1234` สำหรับ Dashboard ผู้บริหาร
- `admin` / `1234` สำหรับทุกเมนู

## วิธีเปิดใช้งานใน VS Code

1. เปิดโฟลเดอร์นี้ใน VS Code
2. เปิดไฟล์ `index.html`
3. คลิกขวาแล้วเลือก `Open with Live Server` ถ้ามี extension Live Server

ถ้าไม่มี Live Server สามารถดับเบิลคลิก `index.html` เพื่อเปิดใน browser ได้เลย

## วิธีเดโมให้ลูกค้าดู

1. เปิด `index.html` สองแท็บ
2. Login ด้วย `admin` / `1234` หรือ `nurse` / `1234`
3. แท็บแรกเลือก `หน้าจอผู้ป่วย`
4. แท็บที่สองเลือก `พนักงานห้องยา`
5. กด Next, Recall, Skip หรือพิมพ์เลขในช่อง Manual เช่น `10` แล้วกดเรียก ระบบจะแสดงเป็น `010`
6. ถ้าพิมพ์ Manual เป็น `020` แล้วกด Next ต่อ ระบบจะเรียกคิวตามลำดับถัดไป เช่น `006` ไม่ใช่ `021`

## การอัปโหลดขึ้น GitHub

ถ้าเครื่องติดตั้ง Git แล้ว ใช้คำสั่ง:

```powershell
git init
git add .
git commit -m "Initial pharmacy queue demo"
git branch -M main
git remote add origin https://github.com/YOUR_USER/YOUR_REPO.git
git push -u origin main
```

จากนั้นเปิด GitHub Pages ได้ที่ Settings > Pages แล้วเลือก branch `main` และ folder `/root`
